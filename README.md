## Tracks (all mandatory)

1. **Main challenge:** build any application that uses SIE.

   Each request is handled through SIE, and complex tasks can optionally be offloaded to Alibaba Cloud.

   Recommended demos: offloading with a routing dashboard, or an agent on Alibaba Cloud doing tool calling with SIE.

2. **Alibaba visual track (sponsored by Alibaba Cloud, mandatory):** every team creates a visualization and explanation of their solution using Qwen image and/or video generation on Alibaba Cloud; the best one wins this track.
3. **Social media track:** post publicly about what you are building (any platform), using Qwen visuals and sponsor tags; most impressions at judging time wins a small reward.

## Awards

| Award                              | Criteria                                                                    |
| ---------------------------------- | --------------------------------------------------------------------------- |
| Overall winner                     | Best application built around SIE (optional Alibaba Cloud offload rewarded) |
| Alibaba visual track winner        | Best Qwen-generated visual explanation of a solution                        |
| Social media winner (small reward) | Most impressions on a public post at judging time                           |
